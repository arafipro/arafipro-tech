## 原文（英語）

`<app-describtion>`  
I want to create a next.js app that reads data from a .json file.  
JSON file contains 6 different names and gender.  
Create a feature that selects random names,  
and pairs them up in a smooth transition,  
each pair must be in different genders.  
This app is for picking random teams for a boardgame.  
I am on windows 11 and vs code.  
`</app-describtion>`

`<instruction>`  
Create all the needed files and save them in the correct directories please for my Next js app:  
</instruction>

Create a step-by-step plan for the the npx and npm commands for my app into one codeblock in plan A.  
Plan B should just repeat the `<app-describtion>` and `<instruction>` from above please:

ランダムな名前を選択し、スムーズな遷移でペアにする機能を作成します。  
各ペアは異なる性別である必要があります。  
このアプリは、ボードゲームのランダムチームを選ぶためです。  
私はWindows 11とVS Codeを使用しています。  
`</app-describtion>`

`</instruction>`
